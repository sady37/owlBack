**打地鼠真因(3 层)**:① 没有"单一显式世界状态",状态摊在 BedSessionLatch/grid cell belief/track/LongSurvivalAnchor/RadarInBedConfirmedMs/RoomState 各处,每条规则只读子集 → 漏风在"两个只看部分状态的 gate 之间的缝";② 规则是"条件清单(gate-list)"不是状态机 —— OR 越加越长,**构造上开放、永不封闭**;③ "证据缺失/stale"没被建模,真实世界持续给部分观测,不显式建模缺失必处处漏风。根因 = **缺一层"对有限隐状态的显式信念估计"**,在原始多源观测和决策之间。

**用户的数学直觉 = 成熟范式**(他独立重推导出来的):贝叶斯滤波 / HMM / 动态贝叶斯网络(DBN)/ switching state-space。映射:belief 向量 b∈Δ(S);观测 o = 测量更新 `b←diag(P(o|s))·b`(对角阵重加权=贝叶斯);时间推进 = 转移阵 A 连乘(forward 算法);人类逻辑 = A 和 P(o|s) 的条目 + 决策代价(**全可检查=白盒**)。缺证据 = `P(o|s)=I` 不更新,信念由 A+其他源维持 → **这一类 bug(含 9h person_silent)整类消失,不再补 gate**。参考锚点:Thrun/Burgard/Fox《Probabilistic Robotics》(2005,逐字编成教科书)、Rabiner HMM tutorial(1989)、Kevin Murphy DBN 论文(2002)、HSMM(显式状态时长,治"久态"误报,现行 10min/2h 硬阈值=其零方差退化版)。商用跌倒检测多走深度学习黑箱,用户**故意选不时髦但满足"可解释+完备+能注规则"约束的贝叶斯支**。

**诚实边界(必须分清,否则新框架在矩阵条目上打地鼠)**:完备=**程序完备**(任何 present/absent/stale 组合都有定义后验,漏风消失),**≠ 正确**(S 漏真实模式 / P(o|s) 标错仍自信错,但失效模式变"补状态/调条目",局部可观测可回归);**不创造可观测性**(雷达分不开"地上不动vs床上不动"时矩阵变不出信息,但会输出恰当不确定度让决策不确定时不报/升级人工);**工作量不消失是搬家**(从"枚举规则组合,随条件指数爆炸"→"枚举有限状态+每传感器 P(o|s),随状态线性")。
