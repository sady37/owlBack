2026-06-04 用户拍板，**推翻我之前反复念的"layout 是人工真相、只能人工经 FE 改"**——人类无精确工具画 layout，人画的是**不精确先验**非真相。详尽需求规格在分支 `feat/feedback-lying-learning` 的 `owlBack/doc/feedback_lying_learning_and_layout_authority.md`。

**权威次序**：人工绘制(粗先验) → **AI 修正(默认接受)** → 人类明确否决(**sticky，永久不再绘入该点**)。代码已有骨架(cell `Source: Human/Learned/Unset` + 自学习 SourceLearned 默认生效 + demote 自纠)，差：① sticky 否决(新增 `SourceHumanVeto`/`LearnBlocked` 跨重启跳过学习) ② AI 可修正人画的不精确几何(现 `SourceHuman 不覆盖` 太死)。

**修正分级(命门)**：加性/几何(补金属点、扩墙)= 低风险**默认接受**靠 demote+veto;**会抑制跌倒的(lying/deny/bed)= 高风险(漏报不可逆)不默认接受**，走人类 alarm feedback 门控;翻人类语义标签=不默认翻**只加不改**。

**AI object 下发策略**(firmware 消费 declared areas)：**AI 新生成 fall-affecting object(lying/deny/metal)不下发** → server overlay + DBN 在原始雷达数据判(下发会污染验证用的原始数据、不可逆);**AI 几何外扩可下发**——**铁律只 enlarge 永不 shrink**(缩会漏真目标) + ≤30cm ≤雷达最大边界(合 [[layout_drift_wall_expansion_policy]])。

**Feedback 驱动 lying/sit 学习**(细化现有 `feedback.go AlarmFeedbackIngester`)：
- **verified 真摔 → 擦该处 `SourceLearned` lying(相当于没学过，最强安全律)**；**人工 bed(SourceHuman)不擦**(刻意语义+床上真摔真实存在)，但 `RealFallCount++` 记录，反复真摔触发人工复审不自动擦。
- false_alarm 坐类(Chair/Short Sofa/Behind Table/Wheelchair)→ `RestZoneConfirmed++` 渐进 sit；传感器误差类(Error Pose/Electric/AC/Out-of-Range/Other/Unknown)→ **不进 lying/sit 学习**(Electric/AC 仍可进独立 GhostCount)。
- **躺类(Lying Lounge/Long Sofa)→ confirm 后立即交互**：长期放置→`MarkRestZoneByFeedback(lying)` 永久学;临时→`cell.FallSuppressUntilMs=now+2h`(机制现成);否→不动。坐渐进自学/躺必须人确认(床级抑制更强)。

**拆分**：backend 可独立做=verified-fall 擦 learned lying(人工 bed 不擦)+reason 路由细化+2H 抑制路径;**FE 依赖(另开新会话，producer-first)**=新 reason 选项(Behind Table/Short vs Long Sofa/Out-of-Range/Error Pose，对齐 [[alarm_handle_form_by_category]])+Lounge 交互问询 UI+sticky 否决入口。规格文档 `doc/feedback_lying_learning_and_layout_authority.md` 已在 **main**(用户澄清"单独"指 FE 放新会话，非 git 分支；分支已删回 main 单线)。
