3.3.	MQTT上送内容格式
3.3.1.	发布秒级轨迹数据
秒级轨迹报文格式如下（可只关注payload部分，忽略header内容）：
{
"header":{
"traceId":"xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx", "payloadVersion":1,
"brand":"qinglan",
"timestamp":1234567890123, "method":"device-penetrate"
}"payload":{
"deviceCode":"F59D3E873F8F",
"position":"12D4D5FEE0089"
}
}

其中deviceCode为设备UID，position为base64编码的16字节*N长度的字节数组，N为雷达设备侦测到的人数。
在有人状态时，轨迹数据以1秒1次的频率进行上报。
在无人状态时，轨迹数据以30秒1次频率上报，目标ID固定为88.
在有人状态下，每16字节代表1个人，其定义如下：
字节	属性名称	定义
0	目标ID	有人状态时，数值取值0-7，代表人员编号；
无人状态时，数值固定为88，表示无人
1~3	轨迹坐标	1-3字节分别为x/y/z坐标。
x和y坐标单位为分米，取值范围-127~127；z坐标单位为厘米，取值范围0-255
4-11	预留字段	预留调试使用
12	剩余时间	单位为秒，取值0-60，仅在自动测量边界时使用
13	人员姿态	0: 初始化 1: 行走 2: 疑似跌倒 3: 蹲坐 4: 站立 5：跌倒确认 6: 卧
7: 疑似坐地 8: 确认坐地 9: 普通床上坐起 10: 疑似床上坐起 11: 确认床上坐起
3、6需配置打开“姿态显示”功能，需升级到202406版本固件才支持。
7、8需配置打开坐地告警开关，需升级到202407以上版本固件才支持
9-11需配置打开床上坐起开关，需升级到202501以上版本固件才支持
14	人员事件	0：无事件 1：进入房间 2：离开房间 3：进入区域 4：离开区域 
如设备上报了不在上述事件定义值的事件可忽略
15	区域ID	在14字节内容为3或4时，此字段标识人员进出的区域ID



3.3.2.	发布秒级呼吸心率数据
秒级呼吸心率报文格式如下（可只关注payload部分，忽略header内容）：
{
"header":{
"traceId":"xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx", "payloadVersion":1,
"brand":"qinglan",
"timestamp":1234567890123, "method":"device-penetrate"
},"payload":{
"deviceCode":"F59D3E873F8F",
"heartbreath":"12D4D5FEE0089"
}
}
其中deviceCode为设备UID，heartbreath为base64编码的定长16字节的数组。
在有人进入监护床时，秒级呼吸心率数据以2秒1次的频率进行上报；否则不进行数据上报。
呼吸心率报文长度固定为16字节，其定义如下：
字节	属性名称	定义
0	标识符	固定为0，表示实时呼吸心率；
1	呼吸值	单位：次/分钟
2	心率值	单位：次/分钟
3-12，14-15	预留	预留调试使用
13	状态事件	bit 7 & bit 6：代表过去1分钟的睡眠状态
   00：未定义   01：浅睡     10：深睡   11：清醒


3.3.3.	发布分钟级睡眠统计数据
分钟级呼吸睡眠报文格式如下（可只关注payload部分，忽略header内容）：
{
"header":{
"traceId":"xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx", "payloadVersion":1,
"brand":"qinglan",
"timestamp":1234567890123, "method":"device-penetrate"
},"payload":{
"deviceCode":"F59D3E873F8F",
"hbstatics":"12D4D5FEE0089"
}
}
其中deviceCode为设备UID，hbstatics为base64编码的定长16字节的数组。
在有人进入监护床时，分钟级呼吸睡眠数据以1分钟1次的频率进行上报；否则不进行数据上报。
报文长度固定为16字节，其定义如下：
字节	属性名称	定义
0	标识符	固定为0xff，表示为睡眠统计；
1	实时呼吸值	单位：次/分钟
2	实时心率值	单位：次/分钟
3-4	睡眠统计信息	睡眠算法未公开，本字段信息不公开
5	分钟级平均呼吸	单位：次/分钟
6	分钟级平均心率	单位：次/分钟
7-12	睡眠统计信息	睡眠算法未公开，本字段信息不公开
13	状态事件	过去一分钟出现的状态/事件
bit 1 & bit 0代表过去1分钟的呼吸状态: 
   00: 呼吸正常     01: 呼吸过低   10: 呼吸过高   11: 呼吸暂停
bit 3 & bit 2：代表过去1分钟的心率状态
   00: 心率正常   01: 心率过低    10: 心率过高   11: 未定义
bit 5 & bit 4：代表生命体征情况
   00: 状态正常   01: 未定义    02: 未定义    11: 生命体征弱
bit 7 & bit 6：代表过去1分钟的睡眠状态
   00：未定义   01：浅睡    10：深睡    11：清醒
14-15	睡眠统计信息	睡眠算法未公开，本字段信息不公开

注意，除生命体征弱异常外，一般不建议基于分钟级的呼吸心率事件立刻产生报警。
此外，分钟级数据种的睡眠状态是实时计算，和每天睡眠报告中长时间计算的睡眠状态会略有差异。


3.3.4.	发布分钟级轨迹统计数据
分钟级轨迹统计报文格式如下（可只关注payload部分，忽略header内容）：
{
"header":{
"traceId":"xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx", "payloadVersion":1,
"brand":"qinglan",
"timestamp":1234567890123, "method":"device-penetrate"
},"payload":{
"deviceCode":"F59D3E873F8F",
"posstatics":"12D4D5FEE0089"
}
}
其中deviceCode为设备UID，posstatics为base64编码的定长16字节的数组。
不管是否有人，此数据以固定1分钟1次的频率进行上报；
分钟级统计报文长度固定为16字节，其定义如下：
字节	属性名称	定义
0	版本标识符	当前取值1或2
1	人数	当前上报时刻雷达检测到的人数。取值0-8
2~3	行走距离	过去一分钟统计的行走距离，单位为米. 
取值范围 0-32767，采用Big-Endian字节序填写。
注意：在多人情况下不做统计
4	行走时长	过去一分钟统计的行走时间，单位为秒
注意：在多人情况下不做统计
5	静坐时长	过去一分钟统计的坐立时间，单位为秒
注意：在多人情况下不做统计。静坐只在顶装3*3米以内进行识别，超过此范围不识别。
6	在床时长	过去一分钟统计的在监护床时间，单位为秒
注意：在多人情况下不做统计
7	站立时长	过去一分钟统计的静止时间，单位为秒
注意：在多人情况下不做统计
8	多人时长	过去一分钟统计的有多人存在的时间，单位为秒
这段时间将不做行走距离、行走时长、静止时长等统计
9	标志	在字节0取值为>=2时使用，否则不能使用
Bit 0：标识当前是否在进行呼吸心率测量
其他bit尚未使用
10~15	rsv	未开放使用
