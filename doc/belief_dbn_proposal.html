从硬阈值到动态贝叶斯网络(DBN)的跌倒检测重构

面向项目评审委员会 — 思路 · 数学论证 · 优势 · 边界

wisefido-sensor · 底稿同源:doc/belief_dbn_signal_map.md · 白盒确定性滤波,非黑盒学习

一句话:把当前散落、互相打架的 ~100 条硬阈值规则,收敛成一个因子化动态贝叶斯网络 —— 每条信号按其真实可信方向贡献证据,跌倒判定从"15 个互斗的闸"变成"一个有数学依据、按代价比可调的阈值 $\tau^\*$"。它不是从零搭建:系统已有三层贝叶斯雏形,本方案是把它们统一并补齐两段。
1. 问题与根因 · 2. 核心思路 · ★ 框架(分层/时间反馈) · 3. 信号可信性分级 · 4. 数学论证 · 5. 优势 · 6. 实证 · 7. 边界(诚实) · 8. 复用与路线

1. 问题与根因

现状:误报率高,且每修一个误报就加一条新闸,新闸又和旧闸打架。

对真实案例的根因归类显示,误报大致两半:

≈50% 硬闸互斗
规则逻辑有洞、优先级设反、多套独立时钟无对账。本质是对一堆未标定的代理量各自阈值化,合成工作点不可控。可治
≈50% 输入信号不可信
firmware 的 pose 误判、z 假低、track_id 复用/跳变、静止冻结、被子伪装。部分需多源/硬件

结论:硬阈值范式已到极限 —— 规则数与冲突数一起增长。需要一个能把"不可信信号按其真实可信度加权"的统一框架。

2. 核心思路:因子化 DBN(白盒确定性滤波)

把"现在房间里发生了什么"建成一组隐状态节点,用 60s tick 的观测递推它们的后验。后验既是中间过程,也是最终输出。

隐状态节点(快层,per-tick)
  • $R_i$ — track 真伪(real / ghost)
  • $M_i$ — 运动(moving / static)
  • posture — 姿态(由 z 档 + 时长辅助辨识)
  • $O_b$ — 床占用 · $N_r$ — 房间人数 · $T$ — 存在性五态 · $S_{room}$ — 房间九态
外部只读输入:$Z_{cell}$ 空间语义 —— 由独立的 cell engine 长期学习(沙发/床/走道/卫浴),DBN 只读其结果当先验,不卷入它的学习回路。
关键定位:这是白盒确定性滤波 —— 参数(似然比、转移、生存函数)由领域知识 + 真机数据离线标定,运行时不做动态阈值调制。可解释、可审计、可回放,符合医疗级要求。

★ 框架:几层输入 · 几层网络 · 最终输出 · 时间反馈

分层架构一览(委员会重点)。整体 = 3 类输入 → 1 个特征/门层 → 1 个因子化 DBN(内部 3 级耦合) → 1 个决策读出层,外加 1 个独立 cell engine 提供慢先验,4 个时间反馈入口。

几层输入 / 几层网络 / 最终输出(直答)

问答
几层输入1 个输入层(L0),含 3 类独立模态:radar / sleepad / firmware 事件。经 L1 特征门转成带 LR 的标定观测 $o_t$。
几层网络1 个因子化 DBN(L2),内部按空间尺度3 级耦合:track 级 → bed 级 → room 级,逐级用期望值消息传递。单时间尺度(快层);慢层(空间语义)外置于独立 cell engine,不进 DBN 联合推断。
最终输出L3 读出:跌倒后验(+reason)、房间人数、床占用、风险分级(Attention/Risk)、健康事件;经单一阈值 $\tau^\*$ 判决成告警。每个节点后验既是中间过程也是对外输出。

如何引入时间反馈(4 个入口)

时间反馈是 DBN 区别于硬阈值的本质 —— 状态带记忆地跨 tick 演化。共 4 个入口:

① 节点内 $t\!-\!1\!\to\!t$ 递归 + 遗忘(快, 核心) —— 每个节点把上一 tick 的信念带到当前,再叠新证据,并按 leak 遗忘:

$$L_t=\underbrace{\gamma\,L_{t-1}}_{\text{记忆+遗忘}}+\sum_k\ln\mathrm{LR}_k(o_t)$$

作用:realness 在"走路阶段"建立的 $L_R$,经此带进"静止/倒地阶段"(那时 $v\approx0$ 无当下证据);$\gamma$ 同时是 Boyen–Koller 的 mixing 率(§4.1)。

② HSMM 驻留时长(快) —— "在某状态停了多久" $d$ 是显式半马尔可夫状态,跌倒证据随 $d$ 累积:$\ln\mathrm{LR}_{\text{fall}}(d)=-\ln S_{\text{vol}}(d\mid\text{zone})$。lost-fall 的 pending/recapture 也属此类跨 tick 状态。

③ 慢回路:cell engine 跨天累积 + 衰减 —— 空间语义在天级时间尺度上学习并遗忘,以 $Z_{cell}$ 先验反馈进 DBN(只读)。两时间尺度解耦:快层(秒)推状态,慢层(天)调先验。

④ 标定回路:人工反馈 —— verified 真摔 / false_alarm 标签经反馈通道更新似然标定与空间语义(真摔擦除误学的抑制区),闭环校准。

一句话:输入 3 模态 → 特征门 → 因子化 DBN(track/bed/room 三级,单时间尺度)→ τ* 读出;时间反馈靠 ① log-odds 带遗忘递归 为主,辅以 ② 驻留 HSMM、③ cell 慢先验回路、④ 人工标定回路。

3. 信号可信性分级(本方案的物理基石)

不可信的传感器不是丢弃,而是按其真实方向性赋予似然比。这是"软 > 硬"的根本:硬闸只会"低于阈值就报",做不到方向性区分。

信号可信性正确用法
XY 位置 / still-box可信moving↔static、realness 运动学
sleepad 接触(InBed/LeftBed)可信(独立模态)床占用、区分被子
vital(HR/RR/呼吸暂停)可信(独立模态)真人佐证(有心跳=活人)+ 健康事件
z > 80可信正向 → 站立
z 30–80较可信正向 → 坐
z < 30 / 0噪声(假低)无信息;z 全程不进 fall 压制
pose混淆矩阵只正向:lying→抬 fall;stand/sit 永不压 fall
EnterRoom / LeftRoom 事件可信(正向)event 在=真进出;缺失≠人还在(信号丢失时不发 event)→ 由门距趋势补缺失
安全不对称原则:pose / z 对跌倒只能作正向证据(抬高怀疑),绝不作负向(压制)。理由:正向用错 → 最多误报($C_{FP}$,便宜);负向用错 → 漏报($C_{FN}$,昂贵)。这从根上堵死"firmware 漏判的静止真摔被 pose=stand 压掉"这类漏报。

4. 数学论证

4.1 因子化滤波是精确推断的有界逼近

精确滤波的标准两步递推:

$$P(X^t\mid y^{1:t})\;\propto\;\underbrace{P(y^t\mid X^t)}_{\text{观测}}\int \underbrace{P(X^t\mid X^{t-1})}_{\text{转移}}\,P(X^{t-1}\mid y^{1:t-1})\,dX^{t-1}$$

$X^t$ 维度随 track×bed×room 指数膨胀,故因子化近似为各节点边缘的乘积:

$$P(X^t\mid y^{1:t})\;\approx\;\prod_{c}P(X_c^t\mid y^{1:t})$$

Boyen–Koller 定理(1998):若过程是混合的(转移带遗忘),因子化滤波的相对熵误差不随时间累积,收敛到有界稳态:

$$\mathrm{KL}\!\left(\hat b^{\,t}\,\big\|\,b^{\,t}\right)\;\le\;\frac{\varepsilon}{1-\gamma}$$

其中 $\varepsilon$ = 单步投影误差上界,$\gamma$ = 转移收缩率。现有 bed 滤波器的 leak=0.55 衰减项,正是这个保证有界性的 $\gamma$ —— 不是工程 hack,而是数学必需。

4.2 递归 log-odds(已落地的节点形态)

$$L_t=\gamma\,L_{t-1}+\sum_k \ln\mathrm{LR}_k(o_t),\qquad P_t=\sigma(L_t)=\frac{1}{1+e^{-L_t}}$$

每条证据贡献其对数似然比 $\ln\mathrm{LR}$,按可信方向带符号。bed 占用节点已是此形态,可作通用模板复制到其余节点。

4.3 ghost 融合 = 对真伪边缘化(不是硬阈值)

当前做法把 $R_i$ 取 MAP 后硬条件化,丢掉不确定性。正确做法是边缘化;因 ghost 不会摔($P(\text{fall}\mid\text{ghost})=0$),塌成一行:

$$\boxed{\,P(\text{fall}_i\mid y)=P(\text{fall}_i\mid\text{real},y)\cdot P(R_i{=}\text{real}\mid y)\,}$$

硬闸是 $P(\text{real})\in\{0,1\}$ 的退化特例 —— 它把 $(0,1)$ 开区间整个丢掉,而那恰是出错区间(真摔被误判 ghost → 漏报)。边缘化是同一积分的无损形式。房间人数同理用 noisy-OR:

$$P(\text{room occupied})=1-\prod_{i}\bigl(1-P(R_i{=}\text{real})\bigr)\bigl(1-P(O_b)\bigr)$$

4.4 驻留时长(HSMM 生存函数)

人类先验"老人几乎无法站立静止超过 8 分钟"= 站立驻留生存函数的标定。跌倒证据随驻留时长平滑上升:

$$\ln\mathrm{LR}_{\text{fall}}(d)=-\ln S_{\text{vol}}(d\mid \text{zone}),\qquad S_{\text{vol}}(d)=P(\text{自愿静止持续}>d)$$

硬阈值"8 分钟报警"是 $S_{\text{vol}}$ 退化成阶跃的特例。真实生存函数平滑 → 后验平滑 ramp → 由 $\tau^\*$ 决定有效报警时刻,且按场景(zone)条件化。

4.5 贝叶斯决策:15 个闸 → 1 个阈值

最优动作由完整后验 + 代价矩阵决定:

$$\text{alarm}\iff P(\text{fall}\mid y)>\tau^\*,\qquad \tau^\*=\frac{C_{FP}}{C_{FP}+C_{FN}}$$

阈值从漏报/误报代价比直接导出,作用在标定后的真后验上。散落的 15 条互斗闸坍缩为一个有原则、可单调调节的旋钮。

4.6 可行 scope 的信息论上界

数据处理不等式界定了能力边界:任何估计携带的状态信息不超过观测本身。

$$I(\text{state};\hat{})\;\le\;I(\text{state};\text{观测})$$

故可辨识范围被可信信号框死:realness、moving/static、bed 占用、fall-as-anomaly 可辨识;细粒度 {sit/stand/lying} 仅在 z>30 或跨模态可信时辨识。DBN 不制造观测里没有的信息 —— 这是诚实的能力声明。

5. 优势

维度硬阈值现状DBN 方案
误报治理15 闸互斗,工作点不可控1 个代价比阈值 $\tau^\*$,消掉"互斗型"那一半误报
不可信信号低于阈值就报,无方向性按真实方向标 LR;pose/z 只正向,堵漏报
ghost 处理硬判后直接剔除(判错=灾难)边缘化,软加权,无损保留不确定性
误差稳定性规则越加越乱Boyen–Koller 有界,leak 即 mixing 率

核心优势一句话:DBN 不是"更复杂",而是把误报/漏报的权衡收敛到一个有数学依据、可调、可审计的点,同时用"软证据 + 安全不对称"把两类最贵的错误(ghost 误剔、漏判压制)从根上堵住。

6. 真机实证

6.1 可分的多数(DBN 赢)

带 lying 姿态的真摔、坐姿/休息区误报、ghost、门区离开 —— 靠 pose-lying 正向 / realness / 空间语义 / 门距趋势干净路由。

6.2 cd2b(201 卧室)冻结 ghost —— realness 是正解

真相:跌床 → 雷达丢真人 → track 跳到椅子并冻住(ghost)→ 被当作"人还在"压掉跌倒告警 → 漏报。判别全靠可信的 XY 运动学(跳速超室内-老人天花板 + 卡死近零方差 + 距门远 + 连续性断)→ realness 判 ghost → 真人 Lost 浮出 → 应报。(此判别完全不碰 pose/z。)

6.3 不可分对 —— 诚实的残差

firmware 漏判的静止真摔 vs 冻结误报,在所有可信信号上同构,唯一分离杠杆是空间语义(此处久站是否正常)。这是信息论残差,任何算法都无法在可信信号上突破。

7. 边界(诚实声明)

  • 治不了的:firmware 完全漏判 + 信号冻结的场景,只剩空间语义一根杠杆;真正的下限需加传感器(多雷达覆盖盲区 / 床边压力垫),非滤波层能补。
  • 前置依赖:后验标定(似然比、生存函数尾形)需真机 oracle 数据;反馈通道已在持续产真值标签,可用于反验。
  • 检测延迟下限:bedside 类场景的延迟被"正常离床外出时长"顶死(实测约 6–8 分钟),这是物理下限不是算法缺陷。
