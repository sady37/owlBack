2. 三态状态机（核心）

TransitionVacant note right of Leaving IsPresent() = true subset_invariant 仍算占用 Count 保留（不归零） end note note left of Vacant Count = 0 (显式 set) LastExitTs 更新 ground truth — 不可被 stale cache 推翻 end note
Leaving 的意义（老人友好）：老人坐起 / 试探下床 / 短时压感消失，几秒内回弹的话不该 误报 LeftBed。Leaving 是 Occupied 与 Vacant 之间的软离开中间态，timer 窗内可回滚。

3. Score 模型（Scorer）

scorer.go · 详 zone_rules_eval.md

pos = max(enter.strength_decayed, sustain.strength_decayed)
       + recent_enter_bonus (只 sustain 活时加 +15)
neg = leave.strength_decayed
score = pos - neg     ∈ [-100, +100+bonus]
设计规则为什么
多源同方向取 max 不 sum防 sleepace + radar 同向叠加假强
反向 latch高优先级 evidence 10s 拒反向厂家压感 90 / radar 80 是权威窗口
decay120s 线性走完一档signal 自然老化避免永远 latch
enter / leave互斥清零一方触发清另一方累积
sustain独立通道 (HR+RR>0)"在床"持续证据，与 enter 同档 80

4.1.1 sustain 信号源（关键 — 决定 LastEvidenceTs 刷新）

设计不变量（2026-05-20 用户拍板）：
① sleepad vital（HR/RR / sleep-stage）= in-bed 信号（接触式压感证据，可发 sustain）
② sleepad vital 缺失 ≠ 反证不在床（sustain 是 positive-only 通道，不进 leave 路径）
③ radar HR/RR ≠ in-bed 信号（雷达可在床外 detect 到坐沙发的人 HR/RR；不发 bed sustain）
④ radar in-bed 由 firmware 的 InBed/LeftBed alarm（已 in-bed-area 判定）走 adapter_radar
Source触发条件是否发 bed sustain说明
adapter_vital (HR/RR)仅 sleepad device_type + HR>0 AND RR>0 fresh✅2026-05-20 修订：过滤 radar 排除（vital_source.go isSleepad gate）
adapter_sleepace (sleep-stage)sleepad 报 sleep_stage ∈ {1,2,4}✅2026-05-20 新增：覆盖 HR/RR=-1 配置的 sleepad（BM87225200677 类）
radar HR/RR—❌不进 bed zone；radar firmware 自己的 InBed alarm 才是床上证据
sleepad vital 缺失—❌（不进 leave）"缺证据 ≠ 反证据"；离床判定由 sleepad LeftBed event 或 sleepad sustain stale 决定
历史 bug（已修复 2026-05-20）：BM87225200677 之类的 sleepad 配置只发 sleep_stage（HR/RR=-1）， 不发 HR/RR。sensor 重启后 startup_initial_publish 设 bed_status=1，sleepad 不重新发 InBed （只在 transition 时发），sleep-stage 事件被 adapter_sleepace 忽略 → scorer.LastEvidenceTs 卡死 → 5min 后 repairSubsetInvariant force Vacant → "LeftBed 15m" stale。

双修复：
  • ① adapter_sleepace 消费 sleep-stage event 转 sustain（覆盖 HR/RR=-1 sleepad）
  • ② adapter_vital 加 sleepad device_type 过滤（radar HR/RR 不再误算 bed sustain）

4.3 Vacant transition 的 Count 强 set

engine.go applyTransitionToState 强语义：

case TransitionVacant:
    s.LastExitTs   = nowMs
    s.LeavingSince = 0

Vacant 是 ground truth — engine 内部权威。任何下游消费者都不能用 stale cache 推翻它 （参 §6 Vacant trust 守卫）。

dedup 公式

  • Z = radar NumberPeople（raw，来自 cache）

7.2 Zonealarm.Supervisor → iot:alarm:stream

派生 4 条 zone-level alarm（不重做 engine 工作）：

  • Stay — 停留超时
  • LeftBed — 离床超时
  • NightAbsence — 整夜未归
  • BedNightAbsence — 床上整夜未归

订阅 ZoneEvent + alarm-firer 按 yaml 规则配 timer / threshold。
